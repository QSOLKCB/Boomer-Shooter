# BS-002 — Arcade movement and combat feel

The Foundry Pit runs one 60 Hz match for the operator and three rival machines. Click **Enter the pit**, **Resume** or **Rematch** to request mouse capture with the original pointer gesture. Until Chromium grants it, the game schedules zero combat ticks. A declined request leaves the arena frozen and offers a retry or explicit drag/keyboard play. Keyboard activation of the entry button starts arrow-key play.

## Movement and aim

| Shared controller setting | Classic | Arcade |
| --- | ---: | ---: |
| Walk / sprint (m/s) | 8.5 / 11.5 | 9.6 / 12.8 |
| Ground / air acceleration (m/s²) | 74 / 21 | 104 / 34 |
| Jump speed (m/s) | 7.65 | 8.1 |
| Fresh jump request | Current tick | Current tick and five further ticks |

Arcade consumes the jump request on the first grounded step. Cancellation, death and respawn clear it. Both presets use the pinned character controller's swept collision and diagonal speed limit. Hold right mouse or Q to raise the weapon, narrow the lens and scale turn sensitivity through WeaponFeel. Vise can use the same sights while engaging at range. The world aim ray and the damage resolver own the hit.

## Reading a fight

Weapon events drive amber rivet traces, short cyan repeater pulses and magenta slag trails. Explosion and impact debris shrink near the camera to keep the attacker's silhouette visible. A lamp on an engaged rival pulses as its shot becomes ready. A narrow HUD chevron shows the bearing of a damaging shot or a blast centre. Head impacts brighten the hit marker and a confirmed elimination turns it cyan. Stereo shots use the same camera-relative bearing. Sound is optional and shares the existing twelve-voice limit.

| Rival skill | Reaction after acquisition, before the rival-specific offset | Aim-error range parameter (radians) |
| --- | ---: | ---: |
| Easy | 42 ticks | 0.080 |
| Normal | 23 ticks | 0.032 |
| Hard | 10 ticks | 0.015 |

The authored difficulty entries change target reaction and seeded aim error. Damage, initial health, armour, magazines, cover occlusion and weapon cooldowns come from the same arena for every skill. Respawns exclude occupied starts, prefer starts at least four metres from rivals, then minimise visible rivals and maximise distance. An arena with every start occupied retries next tick.

Green pads return after 540 ticks. Amber pads return after 360 ticks and require a spent reserve. The engine tops up all reserves together. The per-weapon grant is bounded by half the pad amount (rounded up) and the largest deficit against a starting reserve. The pickup notice reports total rounds added. Plates continue to use the original Foundry Pit rule.

Format 2 replays bind movement and difficulty to the canonical state, including pending jump requests. Format 1 selects the BS-001 movement, commands, bot settings and pickup/respawn policy. Browser and Node receipts have same-runtime scope.

## Reproduction

```sh
node --test tests/*.test.mjs
python3 scripts/browser.py --chromium /path/to/chromium --suite all --out /tmp/bs002
python3 scripts/browser.py --chromium /path/to/chromium --suite hosted --url https://qsolkcb.github.io/Boomer-Shooter/ --out /tmp/bs002-pages
```

The local suite packages the same files as Pages under `/Boomer-Shooter/`. It exercises real mouse capture, release, rematch, keyboard input, and replay import. The hosted probe reads the deployed source revision, then scores a real frag and starts a rematch with the warmed browser offline.
